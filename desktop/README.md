# EMV для Windows

Программа на Electron: окно с сайтом https://emv.one, значок в трее, экран
«нет связи», автообновление, а также:

- **уведомления** Windows о новых заказах и письмах (Входящие и свои папки — фильтры Яндекса часто кладут письма сразу в папку);
- **печать без диалога** документов заказа (счёт, УПД, ТН) на выбранный принтер;
- **папка прайсов**: Excel/CSV из неё сами открываются в CRM → Проценка.

Настраивается в меню «Файл → Настройки…» (или Ctrl+,) и в меню трея.
Это отдельный npm-проект, на сборку сайта он не влияет.

## Команды (из папки `desktop/`)

| Команда | Что делает |
|---|---|
| `npm install` | поставить зависимости (один раз) |
| `npm start` | запустить программу с emv.one |
| `npm run dev` | запустить с локальным сайтом `http://localhost:3000` (`npm run dev` в корне) |
| `npm run icon` | пересобрать `build/icon.png` из `src/app/icon.svg` |
| `npm run dist` | собрать установщик в `dist/` |
| `node scripts/run-selftest.js` | самопроверка папки прайсов и окна настроек |

## Выпуск новой версии

1. Поднять `version` в `package.json` (например, `1.1.0` → `1.1.1`).
2. `npm run dist`.
3. Скопировать на сервер в папку `desktop-releases/` в корне сайта (рядом
   с `package.json` сайта) три файла из `dist/`:
   `EMV-Setup-<версия>.exe`, `EMV-Setup-<версия>.exe.blockmap`, `latest.yml`.

Сайт отдаёт их по адресу `https://emv.one/desktop/<файл>`
(`src/app/desktop/[file]/route.ts`), перезапуск сайта не нужен. Программы
проверяют `latest.yml` при запуске и каждые 4 часа, скачивают обновление
в фоне и предлагают перезапуск. Ссылка для первой установки:
`https://emv.one/desktop/EMV-Setup-<версия>.exe`.

Программа только для сотрудников: она открывает CRM (`/admin`), а файлы
`/desktop/…` отдаются лишь вошедшему сотруднику (клиенту и гостю — 404).
Поэтому установщик скачивают из браузера, войдя в CRM, а программа проверяет
обновления после входа (передаёт cookie сессии). Для клиентов на сайте
ничего не меняется: кнопка «Печать» и папка прайсов есть только в CRM и
только внутри программы.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/main.js` | окно, меню, трей, обновления, связь с сайтом (IPC) |
| `src/preload.js` | `window.emvDesktop` для сайта (типы в `src/lib/desktop.ts` сайта) |
| `src/poller.js` | раз в минуту спрашивает `/api/desktop/poll` и показывает уведомления |
| `src/printing.js` | скачивает файл с cookie окна и печатает через SumatraPDF (`pdf-to-printer`) |
| `src/prices.js` | следит за папкой прайсов, очередь файлов для Проценки |
| `src/settings.js`, `settings.html` | настройки (`%APPDATA%\EMV\settings.json`) |
| `src/offline.html` | экран «нет связи», сам повторяет загрузку |

**Уведомления.** Сайт отвечает только вошедшему сотруднику и учитывает
«Доступ»: о заказах сообщается при доступе к «Заказам», о письмах — при
доступе к «Почте» и настроенном ящике. При запуске программа запоминает
текущее состояние, старое не показывает. Клик по уведомлению открывает
заказ или письмо.

**Печать.** В окне документов заказа у PDF и картинок появляется кнопка
«Печать» (только в программе). Принтер выбирается в настройках, там же есть
«Пробная печать».

**Папка прайсов** (по умолчанию `Документы\EMV Прайсы`). Подпапки
поставщиков создаются сами по списку поставщиков на сайте; символы, которые
Windows запрещает в именах (`"` и т. п.), заменяются на `_`. Файл из подпапки
открывается в Проценке уже с поставщиком и проверкой, остаётся нажать
«Загрузить». Файл из корня папки открывается с выбором поставщика. После
загрузки файл переносится в `Загружено\`. Закрытый без загрузки файл больше
не предлагается, пока не изменится; вернуть его можно через трей →
«Загрузить прайсы из папки».

Установщик не подписан, поэтому при первой установке Windows SmartScreen
покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
